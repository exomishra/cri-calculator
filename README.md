# CRI Calculator

Calculate colorimetric paramters from the spectrum. Instructions are available on the first sheet of the spreadsheet. 

# Description

During my Bachelor of Technology in Engineering Physics, I taught myself the fascinating subject of [Colorimetry](https://en.wikipedia.org/wiki/Colorimetry). I developed a spreadsheet (Excel) based tool that calculated metrics which characterize colors. This calculator takes the visible spectrum as input and calculates:
- Chromaticity coordinates (or color coordinate) in 1931 XYZ space, 1931 xy map, 1964 U*V*W* color space, 1960 uv map.
- Correlated color temperature (CCT)
- Whiteness index (CIE 1986)
- Tint index
- Color Renedering Index

You can find this calculator [here](https://github.com/exomishra/cri-calculator/blob/main/CRI%20Calculator.xlsx).
